## 网页操作
连接 ECE4333_A2_V2 / 12345678，打开 http://192.168.4.1/ 。如果仍是旧网页，强制刷新。
1. 保持小车静止。开启 AI stop detection，让网页出现 stop；其他颜色对象需要 Colour regions 开启。
2. 在镜头前正对放置一个完整停车标志，避免画面边缘裁切和旁边红色物体粘连。
3. 从摄像头镜头到标志所在平面量距离，例如50cm。
4. 在 Object index 下拉框选择 stop，点击 Sample selected object width。界面会固定此次宽度和帧序号。
5. Known distance 输入50，点击 Save calibration。若提示 Vision busy，再点击 Save；看到 Calibration saved 才表示成功。
6. 后续测量表显示中心(cx,cy)、尺寸(w,h)和约距离。保存时小车停止，需要手动恢复行驶。标定也会用于发送给 UNO 的停车牌距离；重新检查停车行为。
7. 标定后把同一个标志分别放在例如30cm和80cm，记录测量与实际距离，评估误差；不要只用标定点证明准确率。
8. 红、蓝、绿、橙区域可分别选择并标定。每种颜色只保留一个K，同颜色但不同实际大小的物体不能共用准确距离。
9. 标定保存在ESP32 NVS中，正常重启保留。换打印尺寸/摄像头分辨率/镜头后重新标定。Clear selected calibration将当前类型恢复为未标定。

## 算法和边界
位置是320×240图像的二维像素坐标，原点左上，x向右、y向下；不是世界坐标。区域中心对颜色对象是像素质心。
FOMO负责确认停车标志及位置，不能用它的响应区域直接当物体真实宽度。程序另找位于FOMO位置附近的红色连通区域，获得像素外接框宽高；这一步即使关闭独立颜色显示仍运行。它是基于颜色的尺寸估计，不是精确轮廓分割；阴影、遮挡、倾斜、红色区域粘连仍会影响结果。
没有匹配红色区域时，UI显示Location only，串口的w/h仍是FOMO响应区域，仅用于定位；size_source=fomo_location_only，size_valid=0，distance_cm=-1，不能作为物体尺寸报告。
K = 标定距离(cm) × 标定宽度(px)；估算距离(cm) = K / 当前宽度(px)。本质上假设同一实际宽度、相机焦距不变、标志基本正对相机，近似估计到物体平面的深度。
未标定、没有尺寸、太小、碰到图像边缘时显示明确原因，而不是把-1当厘米。颜色对象只是红/蓝/绿/橙区域，不代表模型已识别了其他语义类别。
当前最多输出4个结果，只保留置信度最高的一个停车标志和各颜色的最大区域；不支持任意数量物体。任务若要求多个停车牌同时检测，仍需扩展。

## ESP32 串口
Arduino IDE选择ESP32的COM口，串口监视器设为115200。每轮输出JSON，objects中的字段：
- label/confidence：目标标签、AI分数（颜色区域没有AI置信度）。
- cx/cy：中心像素；x/y：区域左上角；w/h：区域像素宽高。
- size_source、size_valid：尺寸来源与测量是否可用于距离。
- distance_cm、distance_valid、distance_reason：距离与有效性/无效原因。
同样的JSON可在 http://192.168.4.1/results 和网页 Raw recognition output 中查看。
示例（仅说明字段，不是实测记录）：stop, cx=160, cy=120, w=40, h=40；若K=2000，则distance_cm=50。
