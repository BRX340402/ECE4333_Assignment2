# Sources and third-party components

User inputs: Assignment 2.pdf; Assignment1_Red_Blue_Green_Complete.zip; ex 2.zip; stop sign.rar; Implementation principle of SmartRobot Car.pdf; lab 1 User Manual（EN）20220816.pdf.

Official ELEGOO legacy repository: https://github.com/elegooofficial/ELEGOO-Smart-Robot-Car-Kit-V4.0
The bundled ArduinoJson-v6.11.1.h, IRremote sources and FastLED-master.zip came from its SmartRobotCarV4.0_V0_20210104.zip. Retain their embedded authorship/license notices. Its old DRV8835 motor mapping is NOT the TB6612 mapping used here.
Servo 1.2.2: https://github.com/arduino-libraries/Servo (packaged upstream library, retain license).
Edge Impulse transfer learning: https://docs.edgeimpulse.com/studio/projects/learning-blocks/blocks/transfer-learning-images
Edge Impulse Arduino deployment: https://docs.edgeimpulse.com/hardware/deployments/run-arduino-1.18

The application/controller modifications, guides and tests in this package were prepared for this assignment. No trained model or measured hardware accuracy is bundled. User-provided photos are included only as the prepared training samples and review sheet for this project.
